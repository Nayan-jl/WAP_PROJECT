# Anime Next Watch Generator

## Description

Anime Next Watch Generator is a web application that helps users decide what anime to watch next. It fetches trending anime data from a public API and allows users to explore, search, and filter anime easily.


## Features

* View trending anime
* Search anime by name
* Filter anime by genre
* View top-rated anime
* Expandable synopsis section
* Responsive design


## API Used

Jikan API (MyAnimeList Unofficial API)
https://docs.api.jikan.moe


## Technologies Used

* HTML
* CSS
* JavaScript 


## Concepts Covered

* API Integration using fetch()
* DOM Manipulation
* Event Handling
* Array Methods:

  * map()
  * filter()
  * sort()
  * find()
